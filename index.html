How it works

Three steps

  1. 1

    Start Minecraft 1.8.9

  2. 2

    Run GyroLoader.exe

  3. 3

    Press RSHIFT in game

Press END to unload the client. The loader updates itself.

FAQ

Questions

Why does my antivirus flag it?

The loader injects a DLL into the game process, and the files are not code-signed. Antivirus software often flags that behaviour, so false positives are possible. Before running it, compare the file's SHA-256 with the checksum shown on this page.

Is it safe for servers?

Using it may be against a server's rules. Check the rules of any server you join. Use at your own risk.

How do I update?

The loader updates automatically when you run it.

How do I uninstall?

Press END in game to unload the client, then delete GyroLoader.exe.
